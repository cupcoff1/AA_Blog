# 个人博客 - 需求文档

## 1. 项目概述

仿 tania.dev 风格的极简个人网站，前后端分离架构，用于学习 Spring Boot + Vue + MySQL 全栈开发。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vue Router + Axios |
| 后端 | Spring Boot 3 + MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 认证 | JWT（管理员）+ GitHub OAuth（评论者） |

## 3. 用户角色

| 角色 | 说明 | 权限 |
|---|---|---|
| 游客 | 未登录用户 | 浏览首页、Blog、Notes、Projects、About Me，查看 Blog 评论 |
| 评论者 | 通过 GitHub 登录的用户 | 以上全部 + 发表/删除自己的评论 |
| 管理员 | 后台账号 | 以上全部 + 登录后台管理所有内容、删除任何评论、修改密码 |

## 4. 页面结构

### 前台（所有人可见）

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `/` | 简洁自我介绍，展示最新 5 篇 Blog、5 条 Notes、6 个 Projects |
| Blog 列表 | `/blog` | 长文技术文章，显示标题、日期、摘要、标签，支持关键词搜索 |
| Blog 详情 | `/blog/:slug` | Markdown 渲染正文，代码高亮，底部评论区（2 层嵌套） |
| Notes 列表 | `/notes` | 短笔记列表，每条显示标题、日期、标签、正文全文，支持关键词搜索 |
| Projects 列表 | `/projects` | 项目卡片列表，显示项目名称、描述、技术栈标签、Demo 链接、GitHub 链接 |
| About Me | `/about` | 个人介绍、技能、联系方式 |

### 后台（管理员可见）

| 页面 | 路径 | 说明 |
|---|---|---|
| 登录 | `/admin/login` | 管理员登录 |
| 仪表盘 | `/admin` | 文章数、笔记数、项目数、评论数、标签使用统计、最近评论 |
| Blog 管理 | `/admin/blog` | Blog 文章列表、删除 |
| Blog 编辑 | `/admin/blog/new` `/admin/blog/:id/edit` | Markdown 编辑器 + 标签 |
| Notes 管理 | `/admin/notes` | Notes 列表、删除 |
| Notes 编辑 | `/admin/notes/new` `/admin/notes/:id/edit` | Markdown 编辑器 + 标签 |
| Projects 管理 | `/admin/projects` | 项目列表、删除 |
| Projects 编辑 | `/admin/projects/new` `/admin/projects/:id/edit` | 项目信息编辑 |
| 评论管理 | `/admin/comments` | 查看、删除评论 |
| 个人资料 | `/admin/about` | 编辑 About Me 内容 |

## 5. 功能清单

### 5.1 访客功能

| 模块 | 功能 |
|---|---|
| 首页 | 简洁自我介绍，展示最新 5 篇 Blog、5 条 Notes、6 个 Projects |
| Blog | 文章列表、文章详情（Markdown 渲染 + 代码高亮）、列表页关键词搜索、查看文章评论 |
| Notes | 笔记列表（显示正文全文 + Markdown 渲染）、列表页关键词搜索 |
| Projects | 项目列表（名称、描述、链接、标签），按 id 倒序 |
| About Me | 个人介绍页（Markdown 渲染） |
| 搜索 | Blog / Notes 列表页各自内置搜索，关键词高亮 |
| 主题 | 暗色/亮色模式切换（localStorage 持久化），响应式布局 |

### 5.2 评论者功能（GitHub 登录，暂未实现）

| 模块 | 功能 |
|---|---|
| GitHub 授权 | 点击登录按钮 → 跳转 GitHub 授权 → 回调后获取用户信息 |
| 评论 | 在 Blog 详情页发表评论（Markdown），支持回复（2 层嵌套），删除自己的评论 |

### 5.3 管理员功能

| 模块 | 功能 |
|---|---|
| 登录 | 用户名 + 密码登录（JWT），Token 刷新，修改密码（BCrypt 加密） |
| Blog | 创建/编辑/删除文章。字段：标题、摘要、正文（Markdown）。slug 自动生成，发布日期自动取当前时间，通过 newTags 当场创建标签 |
| Notes | 创建/编辑/删除笔记。字段：标题、正文（Markdown）。slug 自动生成，发布日期自动取当前时间，通过 newTags 当场创建标签 |
| Projects | 创建/编辑/删除项目。字段：名称、描述、Demo 链接、GitHub 链接。slug 自动生成，通过 newTags 当场创建标签 |
| 标签 | 通过 newTags 在创建内容时当场创建（已存在则复用），公开 GET /api/tags 查询全部 |
| 评论 | 查看所有评论（含嵌套回复）、删除任何评论（级联删除子回复） |
| 文件上传 | 头像 / 文章图片上传至服务器本地目录，支持 jpg/png/webp，≤ 2MB |
| About Me | 编辑个人资料，字段：昵称、头像（本地上传）、个人简介、技能列表、社交链接 |
| 初始化 | 项目启动时自动创建管理员账号（AA_ / 123456）和 About 空行 |
