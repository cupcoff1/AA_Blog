# 个人博客 - 需求文档

## 1. 项目概述

仿 tania.dev 风格的极简个人网站，前后端分离架构，用于学习 Spring Boot + Vue + MySQL 全栈开发。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vue Router + Axios |
| 后端 | Spring Boot 3 + MyBatis-Plus |
| 数据库 | MySQL 8.0 |
| 认证 | JWT httpOnly Cookie（管理员）+ GitHub OAuth httpOnly Cookie（游客） |

## 3. 用户角色

| 角色 | 说明 | 权限 |
|---|---|---|
| 游客 | 未登录用户 | 浏览首页、Blog、Notes、Projects、About Me，查看 Blog 评论 |
| 游客(已登录) | 通过 GitHub OAuth 登录的用户 | 以上全部 + 在 Leave a Note 发表/删除自己的便签 |
| 管理员 | 后台账号 | 以上全部 + 管理所有内容（Blog/Notes/Projects/引语/便签）、修改密码 |

## 4. 页面结构

### 前台（所有人可见）

| 页面 | 路径 | 说明 |
|---|---|---|
| 首页 | `/` | 简洁自我介绍，展示最新 5 篇 Blog、5 条 Notes、6 个 Projects |
| Blog 列表 | `/blog` | 长文技术文章，显示标题、日期、摘要、标签，支持关键词搜索 |
| Blog 详情 | `/blog/:slug` | Markdown 渲染正文，代码高亮，底部评论区（2 层嵌套） |
| Notes 列表 | `/notes` | 短笔记列表，每条显示标题、日期、标签、正文全文，支持关键词搜索 |
| Projects 列表 | `/projects` | 项目卡片列表，显示项目名称、描述、技术栈标签、Demo 链接、GitHub 链接 |
| About Me | `/about` | 管理员便签墙 |
| Leave a Note | `/guest` | 游客便签墙（GitHub 登录后留言，分类 To AA_ / To Website） |

### 后台（管理员可见）

| 页面 | 路径 | 说明 |
|---|---|---|
| 登录 | `/admin/login` | 管理员登录 |
| 首页管理 | `/admin/home` | 引语 CRUD + Hero 图上传 + 改密码 |
| Blog 编辑 | `/blog/new` `/blog/:id/edit` | Markdown 编辑器 + 图片上传 + 标签 |
| Notes 编辑 | `/notes/new` `/notes/:id/edit` | Markdown 编辑器 + 标签 |
| Projects 编辑 | `/projects/new` `/projects/:id/edit` | 项目信息编辑 |

> 管理员增删按钮内联显示在前台页面上（路由守卫保护）。无独立管理列表页。

## 5. 功能清单

### 5.1 访客功能

| 模块 | 功能 |
|---|---|
| 首页 | 简洁自我介绍，展示最新 5 篇 Blog、5 条 Notes、6 个 Projects |
| Blog | 文章列表、文章详情（Markdown 渲染 + 代码高亮）、列表页关键词搜索、查看文章评论 |
| Notes | 笔记列表（显示正文全文 + Markdown 渲染）、列表页关键词搜索 |
| Projects | 项目列表（名称、描述、链接、标签），按 id 倒序 |
| About Me | 个人介绍页（Markdown 渲染） |
| 搜索 | Blog / Notes 列表页各自内置搜索，关键词高亮 |
| 主题 | 暗色/亮色模式切换（localStorage 持久化），响应式布局 |

### 5.2 游客登录功能（GitHub OAuth）

| 模块 | 功能 |
|---|---|
| GitHub 授权 | 点击登录按钮 → 跳转 GitHub 授权 → 回调后 httpOnly Cookie 存 token |
| 便签 | 在 Leave a Note 页发表便签（分类 To AA_ / To Website），删除自己的便签 |

### 5.3 管理员功能

| 模块 | 功能 |
|---|---|
| 登录 | 用户名 + 密码登录，httpOnly Cookie 存 JWT，Token 刷新，修改密码（BCrypt 加密） |
| Blog | 创建/编辑/删除文章。字段：标题、摘要、正文（Markdown）。slug 自动生成（随机后缀防冲突），通过 newTags 当场创建标签 |
| Notes | 创建/编辑/删除笔记。字段：标题、正文（Markdown）。slug 自动生成，通过 newTags 当场创建标签 |
| Projects | 创建/编辑/删除项目。字段：名称、描述、Demo 链接、GitHub 链接。slug 自动生成，通过 newTags 当场创建标签 |
| 标签 | 通过 newTags 在创建内容时当场创建（已存在则复用），公开 GET /api/tags 查询全部 |
| 引语 | 创建/删除首页 Hero 区循环展示的引语 |
| Hero 图 | 上传亮色/暗色主题 Hero 图片 |
| 便签 | 创建/删除 About 页便签（管理员专属），可删除任何人的便签 |
| 文件上传 | 文章图片上传至服务器本地目录，支持 jpg/png/webp，≤ 2MB |
| 初始化 | 首次启动自动创建管理员账号，密码从环境变量 ADMIN_INIT_PASSWORD 读取（未设则随机生成并打印到控制台） |

### 5.4 评论系统

Blog 详情页集成 Utterances（GitHub Issues 评论 iframe），评论数据存储在 GitHub Issues，不经过后端。

## 6. 非功能需求

- 代码遵循 RESTful 规范
- JWT 存储于 httpOnly Cookie，前端不可读（防 XSS 窃取）
- Markdown 渲染经 DOMPurify 消毒（防 XSS 注入）
- 路由守卫保护管理端页面
- 数据库连接表设外键约束（DELETE CASCADE）
