## 1. 实体关系概览

```
┌──────────┐     ┌──────────────┐     ┌──────────┐
│   Blog   │─────│  blog_tags   │─────│          │
└──────────┘     └──────────────┘     │          │
                                       │   Tags   │
┌──────────┐     ┌──────────────┐     │          │
│  Notes   │─────│  notes_tags  │─────│          │
└──────────┘     └──────────────┘     └──────────┘
                                       │          │
```

## 2. 表设计

### 2.1 blog（博客文章）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 标题 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| summary | TEXT | NOT NULL | 摘要 |
| content | LONGTEXT | NOT NULL | 正文（Markdown） |
| published_at | DATETIME | NOT NULL | 发布日期 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.2 notes（笔记）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 标题 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| content | LONGTEXT | NOT NULL | 正文（Markdown） |
| published_at | DATETIME | NOT NULL | 发布日期 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.3 projects（项目）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(255) | NOT NULL | 项目名称 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| description | VARCHAR(500) | NOT NULL | 简短描述 |
| content | LONGTEXT | NULL | 详细内容 |
| demo_url | VARCHAR(500) | NULL | Demo 链接 |
| github_url | VARCHAR(500) | NULL | GitHub 链接 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.4 tags（标签）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(100) | NOT NULL, UNIQUE | 标签名 |
| slug | VARCHAR(100) | NOT NULL, UNIQUE | URL 友好标识 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.5 blog_tags / notes_tags / projects_tags（关联表）

| 字段 | 类型 | 约束 |
|---|---|---|
| *_id | BIGINT | PK, FK → 主表 CASCADE |
| tag_id | BIGINT | PK, FK → tags CASCADE, INDEX |

### 2.6 admin（管理员）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(100) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(255) | NOT NULL | BCrypt 加密 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.7 sticky_notes（便签）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| content | VARCHAR(500) | NOT NULL | 便签内容 |
| color | VARCHAR(20) | NOT NULL | 背景色 |
| rotate | INT | DEFAULT 0 | 旋转角度 |
| category | VARCHAR(20) | DEFAULT 'to_aa' | 分类（to_aa / to_website） |
| author_name | VARCHAR(100) | DEFAULT '' | 作者（空 = 管理员） |
| author_avatar | VARCHAR(500) | DEFAULT '' | 作者头像 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

- `author_name` 为空的是管理员在 About 页创建的便签
- `author_name` 非空的是游客在 Leave a Note 页创建的便签
- API 通过 `?source=admin|guest` 参数隔离

### 2.8 hero_quotes（首页引语）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| content | VARCHAR(500) | NOT NULL | 引语内容 |
| author | VARCHAR(100) | DEFAULT '' | 作者 |
| source | VARCHAR(200) | DEFAULT '' | 作品名 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 3. 设计决策

- 连接表设外键约束（CASCADE DELETE），blog/notes 设 `published_at` 索引，sticky_notes 设 `category` 索引
- MyBatis-Plus `map-underscore-to-camel-case: true`
- 全局 `id-type: auto`
