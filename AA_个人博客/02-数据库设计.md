# 个人博客 - 数据库设计

## 1. 实体关系概览

```
┌──────────┐     ┌──────────────┐     ┌──────────┐
│   Blog   │─────│  blog_tags   │─────│          │
└──────────┘     └──────────────┘     │          │
                                       │   Tags   │
┌──────────┐     ┌──────────────┐     │          │
│  Notes   │─────│  notes_tags  │─────│          │
└──────────┘     └──────────────┘     └──────────┘
                                       │          │
┌──────────┐     ┌──────────────┐     │          │
│ Projects │─────│project_tags  │─────│          │
└──────────┘     └──────────────┘     └──────────┘

┌──────────┐
│ Comments │── parent_id (自引用，嵌套回复)
└──────────┘
     │
     │ blog_id
     │
     └──── Blog

┌──────────┐     ┌──────────┐
│  Admin   │     │  About   │ (单行配置表)
└──────────┘     └──────────┘
```

## 2. 表设计

### 2.1 blog（博客文章）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 标题 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| summary | TEXT | NOT NULL | 摘要 |
| content | LONGTEXT | NOT NULL | 正文（Markdown） |
| published_at | DATETIME | NOT NULL | 发布日期 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.2 notes（笔记）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(255) | NOT NULL | 标题 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| content | LONGTEXT | NOT NULL | 正文（Markdown） |
| published_at | DATETIME | NOT NULL | 发布日期 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.3 projects（项目）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(255) | NOT NULL | 项目名称 |
| slug | VARCHAR(255) | NOT NULL, UNIQUE | URL 友好标识 |
| description | VARCHAR(500) | NOT NULL | 简短描述 |
| content | LONGTEXT | NOT NULL | 详细介绍（Markdown） |
| demo_url | VARCHAR(500) | 可空 | Demo 链接 |
| github_url | VARCHAR(500) | 可空 | GitHub 链接 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.4 tags（标签）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| name | VARCHAR(100) | NOT NULL, UNIQUE | 标签名 |
| slug | VARCHAR(100) | NOT NULL, UNIQUE | URL 友好标识 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 2.5 blog_tags（Blog-标签中间表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| blog_id | BIGINT | PK | 文章 ID |
| tag_id | BIGINT | PK | 标签 ID |

### 2.6 notes_tags（Notes-标签中间表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| notes_id | BIGINT | PK | 笔记 ID |
| tag_id | BIGINT | PK | 标签 ID |

### 2.7 projects_tags（Projects-标签中间表）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| project_id | BIGINT | PK | 项目 ID |
| tag_id | BIGINT | PK | 标签 ID |

### 2.8 comments（评论）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| blog_id | BIGINT | NOT NULL | 关联的文章 ID |
| content | TEXT | NOT NULL | 评论内容（Markdown） |
| parent_id | BIGINT | 可空 | 父评论 ID，用于嵌套回复 |
| author_name | VARCHAR(100) | NOT NULL | GitHub 用户名 |
| author_avatar | VARCHAR(500) | NOT NULL | GitHub 头像 URL |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.9 about（个人资料）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | 固定为 1，单行记录 |
| nickname | VARCHAR(100) | NOT NULL | 昵称 |
| avatar | VARCHAR(500) | NOT NULL | 头像图片路径（上传存储） |
| bio | TEXT | NOT NULL | 个人简介（Markdown） |
| skills | JSON | 可空 | 技能列表 |
| social_links | JSON | 可空 | 社交链接 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

### 2.10 admin（管理员）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(100) | NOT NULL, UNIQUE | 用户名 |
| password | VARCHAR(255) | NOT NULL | 密码（BCrypt 加密） |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 3. 设计决策

- **不在数据库层建外键约束**：外键级联和校验逻辑在后端（MyBatis-Plus）实现，避免与逻辑删除冲突，同时能返回清晰的业务错误信息。

## 4. 初始化数据

### 4.1 管理员账号

项目启动时检查 admin 表，无记录则自动插入默认账号：

| username | password |
|---|---|
| AA_ | BCrypt(`123456`) |

### 4.2 About 单行

项目启动时检查 about 表，无记录则自动插入空行（id=1），管理员登录后台后自行编辑。

### 4.3 初始化方式

通过 Spring Boot 启动类（CommandLineRunner）在项目首次启动时自动检查并插入，BCrypt 密码在 Java 代码中实时加密，不硬编码到 SQL。

```java
// 伪代码
if (adminMapper.count() == 0) {
    Admin admin = new Admin();
    admin.setUsername("AA_");
    admin.setPassword(bCryptPasswordEncoder.encode("123456"));
    adminMapper.insert(admin);
}
if (aboutMapper.count() == 0) {
    About about = new About();
    about.setId(1L);
    about.setNickname("AA");
    aboutMapper.insert(about);
}
```
