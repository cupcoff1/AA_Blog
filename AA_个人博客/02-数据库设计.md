# 个人博客 - 数据库设计

## 1. 实体关系概览

```
┌──────────┐     ┌──────────────┐     ┌──────────┐
│   Blog   │─────│  blog_tags   │─────│          │
└──────────┘     └──────────────┘     │          │
                                       │   Tags   │
┌──────────┐     ┌──────────────┐     │          │
│  Notes   │─────│  notes_tags  │─────│          │
└──────────┘     └──────────────┘     └──────────┘
                                       │          │
┌──────────┐     ┌──────────────┐     │          │
│ Projects │─────│project_tags  │─────│          │
└──────────┘     └──────────────┘     └──────────┘

┌──────────┐     ┌───────────────┐
│ Comments │────→│ parent_id     │ (自引用，嵌套回复)
└──────────┘     │ blog_id → Blog│
                 └───────────────┘

┌──────────┐     ┌──────────┐     ┌──────────────┐     ┌──────────────┐
│  Admin   │     │  About   │     │ StickyNotes  │     │  HeroQuotes  │
└──────────┘     └──────────┘     └──────────────┘     └──────────────┘
```

| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

## 3. 设计决策

- **不在数据库层建外键约束**：外键级联和校验逻辑在后端（MyBatis-Plus）实现，能返回清晰的业务错误信息
- **camelCase 映射**：MyBatis-Plus `map-underscore-to-camel-case: true`，实体字段用 camelCase，数据库列用 snake_case
- **ID 策略**：全局 `id-type: auto`，About 表手动设 id=1
