## TypeScript

### 概述

- JavaScript 的超集，加了类型系统
- 写代码时 IDE 检测类型错误，编译时不通过
- 官方文档：https://www.typescriptlang.org/zh/

### 基本类型

```ts
let name: string = "AA"
let count: number = 10
let published: boolean = true
let tags: string[] = ["Java", "Spring"]
let anything: any = {}       // 任意类型，尽量少用
let nothing: null = null
```

### interface — 定义对象形状

```ts
interface BlogVO {
  id: number
  title: string
  slug: string
  summary: string
  content?: string     // ? 表示可选
  publishedAt: string
  tags: TagVO[]
}
```

### type vs interface

- `interface` — 定义对象结构，可被扩展（`extends`）
- `type` — 更灵活，可定义联合类型、交叉类型
- 大多数场景用 interface，复杂场景用 type

### 函数类型标注

```ts
function add(a: number, b: number): number {
  return a + b
}

const fetch: (url: string) => Promise<BlogVO> = async (url) => {
  return await axios.get(url)
}
```

### 泛型

```ts
// 后端 Result<T> 的概念类似
interface Result<T> {
  code: number
  message: string
  data: T
}

// 使用
const res: Result<BlogVO> = await api.get('/blog/slug')
res.data.title  // IDE 自动提示 title 字段
```

### TS 在 Vue 3 中

- `<script setup lang="ts">` — 组件中用 TS
- `defineProps<{ title: string }>()` — 类型标注的 props
- `ref<BlogVO | null>(null)` — 泛型 ref

## 前端工具

### Vite

- 前端构建工具，比 Webpack 快
- 开发：`npm run dev` → 启动本地开发服务器，热更新
- 构建：`npm run build` → 打包压缩 → dist/ 输出
- 官方文档：https://cn.vitejs.dev/

### Vue Router

- Vue 官方前端路由库
- 拦截 URL 变化，无刷新切换组件（SPA）
- 工作方式：匹配路由表 → 替换 `<router-view>` 区域的组件
- 用户感觉像换页，实际只是组件切换，NavBar/Footer 保持不变
- 官方文档：https://router.vuejs.org/zh/

### Axios

- HTTP 请求库，封装 fetch/XMLHttpRequest
- 请求/响应拦截器：统一加 Token、统一处理 401
- 官方文档：https://www.axios-http.cn/

### marked + highlight.js

- `marked` — Markdown → HTML 渲染
- `highlight.js` — 代码块语法高亮
- 文档：https://marked.js.org/ | https://highlightjs.org/

- 流程：marked 渲染 HTML → 提取 h2/h3 标签 + id → 生成目录链接 → 点击锚点跳转

## 前端项目实现链路

### 搭建顺序

```
1. 项目配置
   vite.config.ts → 跨域代理
   main.ts → 注册 Router + 全局样式

2. 基础层
   api/index.ts → Axios 实例 + 拦截器（Token、401 处理）
   types/ → TS 类型定义（和后端 VO 对应）
   router/index.ts → 路由表

3. 布局层
   App.vue → NavBar + <router-view> + Footer
   style.css → CSS 变量（亮/暗色主题）+ 字体

4. 共享组件
   MarkdownRenderer / TagBadge / CommentItem / ThemeToggle ...

5. 前台页面（按访问频率）
   首页 → Blog 列表 → Blog 详情（含评论）→ Notes → Projects → About

6. 后台页面
   登录 → 后台布局壳 → 管理列表页 → 编辑页 → 评论管理 → 个人资料
```
