# 个人博客 - 前端设计

## 1. 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Vue 3（Composition API，`<script setup lang="ts">`） |
| 语言 | TypeScript |
| 构建 | Vite 8 |
| 路由 | Vue Router 4 |
| HTTP | Axios（泛型封装，响应拦截器自动解包 Result.data） |
| Markdown | marked + marked-highlight + highlight.js |
| 评论 | Utterances（GitHub Issues 评论 iframe） |
| 图标 | Lucide Vue |
| 主题 | CSS 变量 + localStorage 持久化 |

## 2. 视觉风格

仿 tania.dev 极简设计。

**布局** — 左侧侧边栏 + 右侧内容区，桌面端 900px+ 显示侧边栏，移动端隐藏。

**配色**
- 亮色：米白底 `#fdf9ee` + 深灰文字 + `#b12d6c` 粉色链接
- 暗色：深灰底 `#1c1c20` + 浅灰文字 + `#c892e7` 紫色链接

## 4. 组件

### 布局
- `App.vue` — 根布局
- `components/Sidebar.vue` — 侧边栏导航（Logo + 导航链接 + 主题切换 + 退出）

### 共享组件
- `components/LogoIcon.vue` — SVG Logo 图标
- `components/TagEditor.vue` — 标签编辑组件（v-model）

### 前台
- `views/HomePage.vue` — Hero 区 + 最新 Blog/Notes/Projects
- `views/BlogListPage.vue` — 搜索 + 文章列表 + 管理按钮
- `views/BlogDetailPage.vue` — Markdown + 目录 + Utterances 评论
- `views/NotesPage.vue` — 搜索 + 笔记列表 + 管理按钮
- `views/ProjectsPage.vue` — 项目卡片 + 管理按钮
- `views/AboutPage.vue` — 管理员便签墙（增删）
- `views/GuestWall.vue` — Leave a Note（GitHub 登录 → 分类便签墙 → 删自己的）

### 后台
- `views/admin/LoginPage.vue` — 登录
- `views/admin/HomeAdminPage.vue` — 引语 CRUD + Hero 图上传 + 改密码
- `views/admin/BlogEditPage.vue` — 文章编辑（Markdown + 图片上传 + 标签）
- `views/admin/NotesEditPage.vue` — 笔记编辑
- `views/admin/ProjectsEditPage.vue` — 项目编辑

## 5. 认证流程

**管理员** — 用户名密码登录 → JWT 存 `admin_token` → 侧边栏出现管理按钮

**游客** — GitHub 登录 → OAuth 回调 → JWT 存 `commenter_token` → Leave a Note 页可发便签

## 6. API 封装

```typescript
const api = {
  get<T>(url, config?): Promise<T>,      // 自动解包 Result.data
  post<T>(url, data?, config?): Promise<T>,
  put<T>(url, data?, config?): Promise<T>,
  delete<T>(url, config?): Promise<T>,
}
```

请求拦截自动附加 `admin_token` 或 `commenter_token`，响应拦截 code≠200 时抛异常，401 清除 token。

## 7. 状态管理

| 状态 | 存储方式 |
|---|---|
| admin_token | localStorage |
| commenter_token | localStorage |
| commenter (name, avatar) | localStorage (JSON) |
| 主题 | localStorage + CSS 变量 |
| isAdmin | computed(() => !!localStorage.getItem('admin_token')) |
