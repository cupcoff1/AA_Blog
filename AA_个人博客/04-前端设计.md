# 个人博客 - 前端设计

## 1. 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Vue 3（Composition API，`<script setup lang="ts">`） |
| 语言 | TypeScript |
| 构建 | Vite 8 |
| 路由 | Vue Router 4 |
| HTTP | Axios（泛型封装，响应拦截器自动解包 Result.data） |
| Markdown | marked + marked-highlight + highlight.js |
| 图标 | Lucide Vue |
| 主题 | CSS 变量 + localStorage 持久化 |

## 2. 视觉风格

仿 tania.dev 极简设计。

**布局**
- 左侧侧边栏（Sidebar）+ 右侧内容区
- 桌面端 900px+ 显示侧边栏，移动端隐藏
- CSS 变量控制亮色/暗色主题

**配色**
- 亮色：米白底 `#fdf9ee` + 深灰文字 + `#b12d6c` 粉色链接
- 暗色：深灰底 `#1c1c20` + 浅灰文字 + `#c892e7` 紫色链接

## 4. 组件

### 布局
- `App.vue` — 根布局，登录页全宽，其他页面侧边栏 + `<router-view>`
- `components/Sidebar.vue` — 侧边栏导航（Logo + 导航链接 + 主题切换 + 退出）

### 共享组件
- `components/LogoIcon.vue` — SVG Logo 图标
- `components/TagEditor.vue` — 标签编辑组件（v-model 绑定，复用于博客/笔记/项目编辑页）

### 前台
- `views/HomePage.vue` — Hero 区（引语轮播 + 图片）+ 最新 Blog/Notes/Projects
- `views/BlogListPage.vue` — 搜索框 + 文章列表 + 管理员增删按钮
- `views/BlogDetailPage.vue` — Markdown 渲染 + 目录导航 + 评论
- `views/NotesPage.vue` — 搜索框 + 笔记列表（全文 Markdown）+ 管理员增删按钮
- `views/ProjectsPage.vue` — 项目卡片网格 + 管理员增删按钮
- `views/AboutPage.vue` — 便签墙 + 管理员内联增删

### 后台
- `views/admin/LoginPage.vue` — 用户名密码登录
- `views/admin/HomeAdminPage.vue` — 引语 CRUD + Hero 图片上传预览
- `views/admin/BlogEditPage.vue` — 文章编辑器（Markdown + 图片上传 + 标签）
- `views/admin/NotesEditPage.vue` — 笔记编辑器
- `views/admin/ProjectsEditPage.vue` — 项目编辑器
- `views/admin/CommentsPage.vue` — 评论列表 + 删除
- `views/admin/AboutPage.vue` — 个人资料表单编辑

## 5. 管理体验

管理员登录后，管理入口内联在对应区域：
- 侧边栏导航项旁出现 `[+]` 新建按钮
- 列表页每条记录旁出现编辑/删除按钮
- About 页便签墙出现添加表单和删除按钮
- 侧边栏底部出现退出按钮
- Logo 图标可点击进入首页管理

无独立后台布局壳，管理功能与前台页面复用。

## 6. API 封装

```typescript
// api/client.ts — Axios 泛型封装
const api = {
  get<T>(url, config?): Promise<T>,      // 自动解包 Result.data
  post<T>(url, data?, config?): Promise<T>,
  put<T>(url, data?, config?): Promise<T>,
  delete<T>(url, config?): Promise<T>,
}

// 请求拦截：自动附加 Authorization: Bearer <token>
// 响应拦截：code === 200 → 返回 data；401 → 清除 token 跳登录
```

调用方写法：`const data = await api.get<BlogVO>('/blog/slug')`，无需手动标注类型。

## 7. 状态管理（无 Vuex/Pinia）

| 状态 | 存储方式 | 说明 |
|---|---|---|
| admin_token | localStorage | 登录后存入，请求时带上 |
| commenter_token | localStorage | GitHub 登录后存入 |
| 主题（亮/暗） | localStorage + CSS 变量 | 初始化读取，切换写入 |
| isAdmin | computed(() => !!localStorage.getItem('admin_token')) | 响应式计算，Token 变化时自动刷新 UI |
