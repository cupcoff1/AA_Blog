# 个人博客 - 前端设计

## 1. 技术栈

| 层 | 技术 |
|---|---|
| 框架 | Vue 3（Composition API） |
| 构建 | Vite |
| 路由 | Vue Router 4 |
| HTTP | Axios |
| Markdown | marked |
| 代码高亮 | highlight.js |
| 主题 | CSS 变量 + localStorage |

## 2. 视觉风格

仿 tania.dev 极简设计。

**布局**
- 大量留白，无封面图纯文字
- 顶导 + 底栏，无侧边栏
- 响应式（桌面居中窄栏 + 移动端适配）

**字体**
- 标题：Georgia / Serif 衬线
- 正文：系统字体栈（-apple-system, sans-serif）

**配色**
- 亮色：白底 `#fff` + 深灰文字 + 蓝色链接
- 暗色：深灰底 + 浅灰文字（New Moon 风格）
- 暗色模式切换：CSS 变量 + localStorage 持久化

**导航栏**
```
[AA]  Blog  Notes  Projects  About  🌙
```
- 左边昵称链接回首页
- 右边主题切换按钮

## 5. 状态管理（无需 Vuex/Pinia）

| 状态 | 存储方式 | 说明 |
|---|---|---|
| Token（admin + commenter） | localStorage | 登录后存入，发请求时带上 |
| 当前用户信息 | reactive | GitHub 登录后显示头像 |
| 主题（亮/暗） | localStorage + CSS 变量 | 初始化读 localStorage，切换时写入 |

## 6. API 封装

```js
// api/index.js — Axios 实例
const api = axios.create({ baseURL: '/api' })

// 请求拦截：自动带 Token
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截：401 自动跳登录
api.interceptors.response.use(
  res => res.data,
  err => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      router.push('/admin/login')
    }
    return Promise.reject(err)
  }
)
```
